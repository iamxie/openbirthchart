# Polich–Page ASC 鄰域：根因診斷與正常對照

日期：2026-11-01。範圍：目前 v0.6.5 加後續修正原始碼。只做診斷，未修改產品、LibEphemeris、依賴、封存基準或發布包；新增檔案限於本證據目錄。

## 結論

三個已知大偏差案例的直接根因是：**目前實作採用的連續 Polich–Page 宮位圈族，在 ASC 之前發生折返，因此由天體位置反求宮位位置不是一對一。歸宮函式先依地平線上下／東西側選象限，再用二分搜尋選中其中一根；跨越地平線時換了搜尋分支，造成有限跳躍。**

這些內部解確實滿足目前的宮位圈方程，不是亂數、資料損壞或未收斂值。精確 ASC 身分補正只指定該軸點為第一宮，不會改掉鄰域的幾何多解或分支選擇。提高迭代精度也不會把內部根自動變成 ASC 邊界根。

本診斷確認「目前程式為何如此」，不宣稱已證明唯一正統的占星歸宮規則，也不把 Swiss 一致當成幾何正確的證明。是否拒絕這種退化、另選分支，或重新定義延伸規則，仍屬後續修復設計。

## 二、正向計算如何證明多解

令 `q` 為從 MC 開始的宮位圈赤經參數（度）：`q=0` 對應 MC、30 對應十一宮頭、60 對應十二宮頭、90 對應 ASC。第一象限的極高關係為：

```text
tan(P(q)) = (q / 90) * tan(phi)
```

其中 phi 是地理緯度。由平面與黃道交線，可獨立算出其黃經：

```text
lambda(q) = atan2(sin(ARMC+q),
                  cos(ARMC+q)*cos(eps) - (q/90)*tan(phi)*sin(eps))
```

角度依度數解讀；程式會轉為弧度呼叫三角函式。在 q=90～180，極高比例改為 `(180-q)/90`。七個詳細案例中，這個獨立正向式與現行七個東側／軸點宮頭的最大誤差僅 `1.1368683772161603e-13` 度。

正常案例中，lambda(q) 到 q=90 為止持續前進；三個異常案例卻先越過 ASC 黃經，再折回：

| 案例 | 第一個 ASC 解 q | 另一解 q | 轉折點 q | 超過 ASC 的最大黃經幅度 |
|---|---:|---:|---:|---:|
| 1914-05 | 65.18164404436638° | 90° | 78.30324528590538° | 0.8728008562657408° |
| 2000-07 | 77.27813649965367° | 90° | 84.4764696980179° | 0.6280609020750489° |
| 2027-04 | 76.66443888942823° | 90° | 83.84767807571056° | 0.4341079286922991° |

以 1914-05 為例，ASC=233.95873272508535°。曲線在 q≈65.181644° 已經到達這個黃經，之後前進到 234.8315335813511°，再回到 q=90 的 ASC。因此內部解與邊界解都能正向還原同一個 ASC。

十二個離散宮頭只檢查 q 每隔 30° 的樣本。這三例的折返發生在 q=60～90 的內部，故「十二宮頭順序正常」不足以證明它們之間的連續映射正常。這與已拒絕的五個離散宮頭交錯案例相關，但不是同一檢查已涵蓋的情形。

更細的例子：1914-05 的 `ASC+1e-6°` 在東半圈正向曲線上有三個原像，約 q=65.1816519643、89.9999936956、90.0000011726。公開歸宮函式依地平線分支只採用其中一個；不能把「函式回傳一個值」當成「幾何只有一個解」。

## 三、逆算方程、分支選擇與精度排除

把天體從黃道坐標獨立旋轉成赤經 alpha、赤緯 delta；折返至東側地平線上方後，令 `H=alpha-ARMC`（採該搜尋象限的角距）、`A=tan(delta)*tan(phi)`。宮位圈平面法向量與天體單位向量的內積為零，可以化成：

```text
F(q) = A*q/90 - sin(H-q) = 0,  0 <= q <= 90
F'(q) = A/90 + (pi/180)*cos(H-q)
```

診斷工具先解析求出 F' 的全部臨界點，再對各單調區段分別夾根，避免再次假定整區只有一根。5560 個固定點的獨立根最大方程殘差為 `1.5543122344752192e-15`；公開 API 與最近獨立根的最大環狀宮位座標差為 `1.430511474609375e-6`。在**函式實際選定的折返象限**中，只有三個精確 ASC 出現兩根，其餘固定點均找到一根；這不等於其他象限或未抽樣天體也全域唯一。

精確 ASC 位於地平線，所以 A=-cos(H)，q=90 必是根。當：

```text
F'(90) = -cos(H)/90 + (pi/180)*sin(H) < 0
```

則 F 在 q=90 左側為正，q=0 時為負，區間內還必有另一根。對這三個已確認的北半球東側上升分支，條件是 `0 < H < atan(2/pi) = 32.48163659052975°`。三例 H 分別約 23.602453°、27.941633°、27.721981°；正常 1904-11 是 34.129651°。此條件只描述本次分支的局部 ASC 退化，不是全宮制、全極區的完整有效性判準。

實際 `_hpos_topocentric` 的追蹤顯示：

1. 先用天體的地平線上下狀態決定是否取對蹠點，再按東西側鏡射。
2. 二分步進從 q=45 起，依帶正負號的平面緯度往左右走，沒有枚舉多根或驗證全段單調性。
3. 1914-05 精確 ASC：先到 q=45、67.5、56.25……最後停在 q≈65.1816487，而非 90。其平面緯度殘差僅約 3.33e-7°，因此依 1e-6° 的現行停止條件確實已收斂。
4. ASC+1e-6° 越到地平線下方，觸發對蹠／鏡射分支，回映成 1.0000000894069672。跳躍不是 `floor()` 造成：尚未取整的連續座標本身已經跳躍。

獨立以更嚴格的無因次 F 殘差 `1e-15` 求解，同樣得到內部根位置：1914-05 約 12.172721468145546、2000-07 約 12.57593788332177、2027-04 約 12.55548129631427。精度只微調尾數，不能消除根與根的距離。這個 F 容差不是產品使用的角度容差，也沒有寫回產品。

## 四、補充對照與影響範圍

### 第七宮頭亦有對稱問題

全宮頭的 ±1e-6° 探測，在三例的第一／第七宮頭各出現一次有限跳躍，共六處。用模 12 的連續座標距離比較，分別約 0.827279、0.424062、0.444519 宮；其餘所有探測的最大距離只有 `2.950429916381836e-6` 宮。

1914-05 第七宮頭兩側為 `6.172720909118653 → 7.000000089406967`，符合對蹠幾何，不能只處理名為 ASC 的點。這些是給定 ±1e-6° 的觀測距離，並非新設產品容差；理論不連續由上述根與分支證明支持。

### 黃緯與地理緯度控制

- 固定 1914-05 的 ARMC／黃赤交角，只把地理緯度由 +69.6489° 改成 0、23、50、60、64.13548°，再依同一定義重算 ASC，左側導數均恢復正值，左右結果接近 13／1。這是另列的合成控制，未改封存輸入。
- 三例做 `phi -> -phi`、`ARMC -> ARMC+180°` 的南北鏡射，也重現同樣跳躍。因此不是北半球專屬的程式標籤錯誤。
- 固定三例 ASC 黃經，改天體黃緯為 ±1e-6° 或 ±0.1°，也能切換地平線分支。例如 1914-05：黃緯 −1e-6° 時 1.0000001788139343，+1e-6° 時 12.172720909118652。
- ASC 自身黃緯是零，因此實際／零黃緯兩種模式都存在此問題。一般天體的地平線與分支會受實際黃緯影響；不能以全部強制零黃緯當作修復。

### Swiss 是對照，不是判決

使用封存指定的獨立 Python 執行檔並驗證 SHA-256，呼叫 Swiss 2.10.03 公開 `house_pos`，沒有讀取／修改 Swiss 實作原始碼。七個詳細案例皆測九個偏移量。

三例在 `ASC-1e-6°` 的 Swiss 回傳逐值等於上表產品原始值；精確 ASC 及 ±1e-8° 回傳 1；到 `ASC-3e-7°` 又回到第十二宮內部解。這直接重現「極近宮頭的回傳符合宮頭身分，但離開後仍有跳躍」。本輪只由公開行為確認，不推論 Swiss 內部程式的具體寫法。

先嘗試 `.venv-reference/Scripts/python.exe` 時，uv trampoline 因舊 home 路徑缺失而失敗；隨後依既有封存環境紀錄，改用 `.cache/python/cpython-3.11.16-windows-x86_64-none/python.exe -I` 並通過執行檔 hash 核對。未修理或重建任何環境。
