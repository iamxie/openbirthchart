# HTML report templates

Bundled templates: `zh-TW` (繁體中文, default) and `en-US` (English). Choose the language in the export dialog. English translates the report, SVG labels, warnings and print counters; user-entered names and notes remain unchanged. Two-letter body abbreviations keep the wheel and aspect grid compact; full names appear in the position table and aspect-cell tooltips. The English template retains the warm paper styling and A4 landscape layout.

Copy `zh-TW` to a new folder (for example `en-US`). The export dialog discovers folders on each use; restart/rebuild is not necessary. In the portable Windows bundle these live in `_internal/templates/report/`.

Each folder owns `labels.json`, `report.html`, and `style.css`. Translate string values, `signs`, `bodies`, `shorts`, `genders`, `aspects`, and `warnings`; preserve keys. `signs` follows Aries through Pisces and supplies table names and the wheel's accessible label. The visible zodiac ring uses the same Astronomicon outlines in every language, matching the desktop. `shorts` uses body IDs and should stay short enough for a chart. `house_systems` optionally overrides names keyed by house code. Set `lang` and `template_name`. Identity text remains exactly as supplied by the user. SVG body labels use these dictionaries too.

The engine uses Python `string.Template` (no executable template code). In HTML use `$key` for the escaped top-level label values. Use `$$` for a literal dollar sign. Generated trusted markup slots are: `$wheel`, `$metadata`, `$warnings`, `$positions`, `$houses`, `$matrix`, `$legend`, `$details`, `$notes_content`. Other slots: `$css`, `$version`, `$person`. Legacy `$font_css` and `$license` slots are empty. Do not put untrusted user data into CSS/JS. Names/notes and all label values are HTML-escaped by the renderer.

SVG is generated from the current chart's positions and aspects; no ephemeris calculation or network access happens during export. Only visible bodies and enabled aspects appear. The shared detail sorter controls both desktop and report. Fonts are not embedded or downloaded: CSS uses Microsoft JhengHei, PingFang TC, Heiti TC, LiHei Pro, Noto Sans TC, Noto Sans CJK TC, then sans-serif. This also applies to SVG text and print page numbers. Linux needs an installed Chinese font; glyph metrics and line wrapping can vary between systems. No API credentials, address lookups, profile database or hidden body data are embedded. No JavaScript or external resources are required.

Print baseline: modern Chromium (Chrome/Edge 131+), A4 landscape, 100%, CSS margins 10 mm with a 13 mm bottom margin, browser headers/footers disabled. Five sections each start on a new page. Long detail tables and opt-in notes may flow onto additional pages. Table headers repeat. The `@bottom-center` page margin box uses real `counter(page)` and `counter(pages)` values, not section counts. Browsers without page-margin-box support can read the file but may omit page numbers. Translate `page_number` in labels.json, preserving exactly one `{page}` and `{pages}` placeholder. The renderer escapes literal CSS text and substitutes it at `/* PAGE_NUMBER_CONTENT */` in style.css. Adapt CSS for translated labels and verify print preview; do not reduce fonts until text becomes unreadable.

Since 0.6.4, affected Azimuth charts include `$house_notice` on the chart and positions sections, plus `$azimuth_help` as a sixth, printable section. Both are empty for unaffected charts. Use `$chart_page_class` on the chart section so its print layout can accommodate the notice. Translate `azimuth_notice` and `azimuth_read_more` in labels.json. The article is embedded in the exported file; its anchor works offline. `docs/azimuth.md` is the bilingual source, with Chinese first; run `scripts/build_help.py` after editing to refresh the two bundled HTML fragments. Article selection currently uses English for `lang` values beginning with `en`, and Traditional Chinese otherwise; additional article languages require extending the renderer. Preserve these slots in custom templates so the notice is not lost.

The browser view is continuous with a sticky navigation bar. Navigation and the bottom printing instructions have `screen-only` and are hidden for print. Section headers omit repeated names/branding; name and gender remain in the first section's metadata. `dst_none` is used for zero summer-time adjustment, `dst_value` for nonzero minutes. The determination mode is not exported; UTC is displayed as YYYY-MM-DD HH:mm:ss under its UTC label.

The warm paper surface uses CSS gradients and a tiny embedded SVG noise texture; no external image is required. Print retains warm accents on a white page. Metadata uses `identity-person`, `identity-birth`, `location-fields` and `settings-fields` classes for clear typographic hierarchy. Translate `location_heading` and `settings_heading` for the two metadata group titles. The wheel background is transparent so it follows the screen/print surface.
