# Open BirthChart v0.7.0

2026-11-03 · [GitHub Release](https://github.com/iamxie/openbirthchart/releases/tag/v0.7.0)

## 繁體中文

- 新增獨立的天象時間軸：輸入起訖時間與時區，搜尋水星至冥王星的逆行與 28 組配對的 0°／90°／120°／180° 相位。每十分鐘掃描，再局部細化事件邊界；顯示進度並支援取消。
- 甘特圖呈現容許度內區間與精確成相，揭露行星經過的星座及跨座歷程。詳情可查看區間重疊事件，也可切換到某一時刻。
- 相位容許度改為應用程式共用設定，保存在 `data.sqlite`。舊個人檔案的容許度不會覆寫全域設定；歷史天象使用當次計算的容許度。
- 首輪將十顆行星的位置與速度保存於 `skyhistory.sqlite`；「天象歷史」可在重開後載入，「看實際星盤」直接播放已存資料，不重算星曆。日月只顯示位置，不納入天象相位與逆行。
- 播放器使用獨立圖形物件；無宮位與 ASC／MC，不需要地點。逆行名稱為深棕底、白字與 R，下方列出完整名稱。快轉每次增加 15 fps，最高目標 120 fps；倒播固定 30 fps，暫停保留順播速度。
- 天象文件匯出支援繁中／英文的離線 HTML，甘特圖置頂，適合列印；英文星座圖示與程式一致。
- 個人星盤引擎、固定依賴及星曆資料未升級，既有幾何與時間差異政策保留。

下載 `OpenBirthChart-0.7.0-windows-x64.zip` 並解壓縮整個資料夾，執行 `OpenBirthChart.exe`，保留 `_internal`。不需另裝 Python。完整對應來源是同頁的 `OpenBirthChart-0.7.0-source.zip`，含固定資料、驗證封存與第三方來源；它不同於 GitHub 自動產生的 Source code ZIP。兩包均提供 SHA-256。程式尚未使用程式碼簽章。

資料位於 `%USERPROFILE%\Documents\openbirthchart\`，`data.sqlite` 與 `skyhistory.sqlite` 均未加密。歷史資料不因更改全域容許度自動重算；需重新計算才能套用新規則。

FPS 是播放目標，實際速度取決於機器；效能不足時放慢，不跳過採樣點。十分鐘粗掃與局部搜尋的有限取樣限制、未完成計算不可播放及不支援自動續算等，見 [天象時間軸說明](../SKY_TIMELINE.md)。既有跨 Windows 浮點尾數、宮位與時標差異見 [驗證說明](../VALIDATION.md)。

## English

- New Sky Timeline: choose a time range and time zone to find retrograde intervals and the 28 Mercury–Pluto pairs at 0°/90°/120°/180°. Ten-minute sampling with local refinement, real progress and cancellation.
- Gantt bands show orb intervals, exact aspects and zodiac crossings. Event details expose overlapping intervals and events at a selected instant.
- Shared aspect-orb settings persist in `data.sqlite`. Legacy profiles do not override them; saved sky histories retain the orbs used for that calculation.
- First-pass positions and speeds of ten bodies are stored in `skyhistory.sqlite`. Reopen completed histories and play them without recalculating ephemerides. Sun/Moon positions are shown but excluded from timeline aspects and retrogrades.
- Retained chart items, no houses/ASC/MC or location requirement. Retrograde labels use brown backgrounds, bold white text and R, with a full-name list below. Fast-forward adds 15 fps per click up to a target of 120; reverse stays at 30 fps, and pause preserves the chosen forward speed.
- Bilingual offline HTML exports put the Gantt chart first and support printing. English zodiac icons match the application.
- Natal calculation rules, pinned dependencies and ephemeris data remain unchanged.

Download and extract the entire Windows x64 ZIP; keep `_internal` beside the executable. Python is bundled. The separately attached full source ZIP includes runtime data, regression evidence and dependency source archives; GitHub's automatic source download is not this full archive. SHA-256 files accompany both ZIPs. The executable is not code-signed.

Local databases are unencrypted and remain in the user's Documents directory. Changing shared orbs does not rewrite saved history. Playback rates are targets, not guaranteed display refresh rates; slow rendering does not skip samples. Existing numerical limitations, cross-Windows floating-point differences and finite-sampling limits remain documented.
