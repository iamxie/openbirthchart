Assets: `OpenBirthChart-0.6.7-windows-x64.zip`, `OpenBirthChart-0.6.7-source.zip`, and their `.sha256` files. Keep the Windows folder intact. The source archive includes application/build/test sources, runtime data, immutable numerical archives and exact dependency sources. The executable is not code-signed.

Existing geometry/time limitations remain: see [validation](../VALIDATION.md). Personal profiles stay in the user's Documents directory, outside the portable installation. Back up that database before changing versions.
